# ❄️ FrostSeek

**Find groups faster. Find members smarter.**

All-in-one LFG/LFM group finder with **FrostNet** — the private network that connects every FrostSeek user, no matter the server.

---

### What is FrostSeek?

FrostSeek is a complete group-finding addon for World of Warcraft. It watches chat for you, alerts you when someone needs your role, broadcasts your own recruitment message, and gives you a shared listing board with every other FrostSeek user — no server-side tools, no website, no Discord required.

### What it does

| Module | What you get |
|--------|--------------|
| 🌐 **FrostNet** | A private listing board between FrostSeek users: browse open groups, publish your own, apply with one click. Every listing shows leader, members, roles, ilvl and voice link |
| 🔍 **LFG** (Looking For Group) | FrostSeek reads chat (Trade, General, Yell...) for you and pops up an alert when someone looks for members. Filters by category (Dungeon, Raid, Keystone, PvP, World Boss, Manastorm, Event), by difficulty, and by minimum keystone level. The whisper message is written for you, with your role, class and ilvl |
| 📢 **LFM** (Looking For Members) | When YOU have a group and need people: write the message once, pick the channels, and auto-spam it every X seconds. Auto-invite by minimum ilvl, auto-stop when the group is full, Bonus Coin support for keystones |
| 🚫 **Chat Filter** | Hides LFG/LFM spam from normal chat channels so your chat stays readable. Custom keywords supported. The addon channels are never touched |
| 🏘️ **Community** | Guild browser, guild recruitment messages and a community event board |
| 📊 **Dashboard** | Your ilvl and roles, FrostNet online count, module status and session stats at a glance |
| 🎨 **Themes & Fonts** | Multiple color themes (Frost, Shadow, Void and more) and several bundled fonts to choose from |
| 🌍 **6 Languages** | English, Italian, German, Spanish, French, Portuguese — auto-detected from your game client |

### Supported clients

Vanilla · TBC · WotLK (3.3.5) · WotLK Classic · Cataclysm Classic · Mists Classic · Ascension / custom clients

### Installation

Full step-by-step guides (written for total beginners) are inside the addon folder:

- 🇮🇹 `Guide/Guida_ITA.md`
- 🇬🇧 `Guide/Guide_ENG.md`

Short version: extract the `FrostSeek` folder into `Interface\AddOns\`, make sure the folder is named exactly **FrostSeek**, enable the addon on the character selection screen, then type `/fs` in game.
